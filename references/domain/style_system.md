# 通用页面设计判断

本文件只维护跨模板成立的阅读与证据原则。颜色、字号、坐标、横幅、比例与版式原语来自当前模板 SPEC.md / tokens.css 或视频主题；它们不是通用审批条件。

## 单页阅读

1. 明确本页要传达的判断，让标题、主证据与收束关系可读。
2. 让比较、因果、层级或时序关系决定布局；等权内容才用等分结构。
3. 用尺度、位置、留白与对比建立主次，不用装饰填满空白。
4. 截图、图表和真实产品图获得足以读清证据的面积；保留来源、时间、单位与口径。
5. 文字在实际容器内可读，没有切字、遮挡、越界或图片占位残留。

## 跨页秩序

标题、来源与页码在所选主题下保持稳定秩序。内容变化决定必要节奏，不为强制换版式破坏连续论证。
视频的人物窗口、字幕区、透明性与强调余量按项目 direction 和 Video Craft 契约处理。

## 实际检查

查看当前 PNG 大图，记录第一眼焦点、具体位置和实际发现。与相邻页并看，检查层级、图文关系与主题一致性。
check 的测量是观察依据，不是设计优劣证明；绿色技术检查不能替代事实与内容判断。
