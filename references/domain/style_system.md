# 视觉方向与实操硬标尺（Style System）

这一份是 **PPT 与画面设计的总规则与实操硬标尺**。

- **普世标尺管「不丑、有秩序、像专业咨询/提案稿」，`template` 管「像哪个品牌」**。
- 有品牌模板或参考文件时，按 `../workflow/01_template_intake.md` 加载或提炼 `template_pack`（优先使用 `tokens.css` 与 `skyline_shell.svg`）；无外部模板时，从内置双旗舰模板包（`agency-social-proposal` 或 `consulting-product-strategy`）起步，并严格遵守本文件的硬标尺。

---

## 元规则：先声明读法

每页在 `page_content.json` 里声明 `mode`，决定信息密度与字号下限：

| mode | 场景 | 排版与字号硬标尺 |
|---|---|---|
| `讲` | 现场投屏，注意路径一次性、由讲者驱动 | 显著度严格唯一；密度低；字号下限 **≥ 18px（9pt）** |
| `读` | 会后留档、商业提案、战略报告、可反复细看 | 允许高信息密度、多维矩阵与主次多模块；正文字号 **16–22px**，底线图注 **≥ 12px（6pt）** |

一套 deck 可混排两种模式；未声明时默认按 `读` 处理。

## 一、「五减五加」四大实操硬标尺（必守铁律）

任何模型在生成 1920×1080 幻灯片 SVG 时，必须直接执行以下 4 条量化标尺，不得以“自由发挥”为由突破：

### 标尺 1：75 : 20 : 5 色彩纪律（砍掉彩虹糖色）
- **75% 中性灰白底（Canvas & Surface）**：画布底色与卡片表面只用高明度中性色（如 `#F4F5F7` / `#F8FAFC` 浅灰画布托 `#FFFFFF` 纯白卡片，或 `#FFFFFF` 画布托 `#F4F5F7` 浅灰区块）。
- **20% 炭黑/深空墨色（Ink & Anchor）**：主标题、正文、次要支柱眉条、顶部 KPI 仪表带与底部收口横幅统一用深墨色（`#111111` / `#0F172A` / `#1E293B`）及中灰辅助字（`#4B5563` / `#64748B`）。
- **5% 唯一品牌强调色（Single Brand Accent）**：全页只允许 **1 种**高饱和品牌强调色（如美津浓红 `#E60012`、战略钴蓝 `#0052D9`，以及配套的 5% 浅底色 `#FFF1F2` / `#EFF6FF`），仅用于页眉左竖条、核心主推列/象限、关键涨跌胶囊与标题高亮词。
- **硬红线**：同页有色相的颜色 **≤ 3 种**。**严禁给并列的 3–4 张卡片每列换一个蓝、绿、橙、紫马卡龙彩虹色。** 并列项的主次一律靠「品牌色 vs 炭黑 vs 浅灰」的明度与饱和度差区分。

### 标尺 2：去框化与容器嵌套上限（Container Nesting ≤ 2 层）
- **最多 2 层可见容器嵌套**：画布之上最多允许「大区块底板 → 子实证盒/标签」两层可见容器。**严禁“大框套中框套小框”（Box-in-Box）**，严禁单列内部嵌套 3–4 层圆角边框。
- **左竖条 + 底色明度差替代全包围粗框**：
  - 区分模块优先用 **无描边浅灰/纯白底色块 + 左侧 `4–8px` 实心竖条**（核心主推项用品牌强调色竖条，常规并列项用炭黑/深灰竖条），或用 **瑞士无框网格 + `120–140px` 浅灰水印大数字（`#EAECEF` / `opacity="0.12"`）** 定锚。
  - **严禁给同页所有并列卡片全加粗红框/粗蓝框**（全部加粗框 = 没有重点）。

### 标尺 3：1920×1080 全局天际线与定海神针收口（Skyline Contract）
所有常规内容页（封面与章节转场页除外）共享同一套 1920×1080 纵向天际线坐标，跨页翻动时页眉、正文安全区、底部收口带与页脚严丝合缝：

| 区域 | 推荐 Y 坐标范围 | 精确构造规范 |
|---|---|---|
| **页眉区（Header Zone）** | `y = 56 .. 175` | 左上 `8×54px` 品牌色竖条（`x=60..80, y=64`）+ **观点型 Action Title**（`font-size: 40–46px, font-weight: 800–900`，单行 ≤ 26 字，必须直给判断结论，严禁写“市场分析”之类的纯名词标签）+ 副标题（`font-size: 20–22px`，核心词用 `<tspan fill="var(--accent-brand)">` 高亮）+ 右上角等宽章节锚点胶囊（`x=1540..1840, y=64`）。 |
| **正文安全区（Safe Zone）** | `x = 60..1860`<br>`y = 196 .. 896` | 核心版式构件与图表排布区（宽 `1760–1800px`，高 `700px`）。栅格间距统一取 `24px` 或 `32px` 步长。 |
| **底部定海神针（Takeaway Banner）** | `y = 918 .. 994`<br>（`height = 76px`） | 深色实心收口横幅（`fill="#111111"` 或 `#0F172A`, `rx="8..12"`），左侧嵌品牌色 `TAKEAWAY / 战略收口` 徽章，右侧用 `22–24px` 白字 + 高亮词一锤定音总结全页推论，压住整页重心。 |
| **页脚区（Footer Zone）** | `y = 1028 .. 1045` | 左下角写明数据来源与统计口径（`13–14px` 浅灰字），右下角等宽页码（`01 / 24`）。 |

- **消灭半截空卡铁律**：严禁竖向卡片下半截空置超过 **25%**。若三列/四列竖卡高度 `> 450px`，卡片上半部写策略动作/论点，**下半部必须内嵌「实证盒 / 话题标签盒 / 爆文指标卡」**把高度撑满，或在文案较少时改用「顶部 KPI 仪表带 + 下方中高度卡片」的上下复合结构。

### 标尺 4：三项视觉与卫生禁令（机器硬拦截）
1. **禁令 A — 严禁系统 Emoji 充当图标（`EMOJI_IN_SLIDE_TEXT`）**：
   - 幻灯片 `<text>` 内严禁出现 `🛡️💧🎯⚠️🔥✍️🏷️` 等系统位图 Emoji（跨平台渲染丑陋且转 PPTX 后基线错位）。
   - **正面替代**：一律使用原生 SVG 几何矢量图形（`<circle>`/`<path>`/`<polygon>` 组合图标）或 `font-family="JetBrains Mono, DIN Alternate, monospace"` 的等宽数字编号徽章（`01` `02` `03`）。
2. **禁令 B — 严禁非矩形几何尖端硬塞多行字**：
   - 金字塔/三角形尖端、圆形底部或漏斗窄口处，**必须按当前 Y 坐标处的真实几何弦宽核算字数**。窄尖端内只放 `01` 编号或 2–4 字短词，长段解释一律拉水平引线到外侧矩形卡片排布，严禁文字捅破斜边或圆弧。
3. **禁令 C — 严禁换图后残留底层占位文字与横线切字（`LINE_CROSSES_TEXT` / `TEXT_OVERFLOWS_CONTAINER`）**：
   - 任何图片槽位的文字说明必须包裹在 `<g data-slot="image-placeholder" class="slot-hint-removable">` 中；一旦贴入真实 `<image>`，必须删除该占位组，严禁真照片底下透出 `[图片占位]` 文字。
   - 任何 `<line>` 或 `1px` 分割线 `<rect>` 必须走在容器间距通道内，**绝不可横穿 `<text>` 包围盒**（尤其注意含 `<tspan dy>` 多行文本的总高度）。
   - 胶囊标签（Pill Badge）与窄卡片的 `<rect width>` 必须比内部文字估算宽度多留 **≥ 24px** 余量，防止转入 PowerPoint 后末字自动折行溢出。

## 二、秩序、层级与节奏原则

1. **先立秩序，再做单页**：同一套 deck 共享 `tokens.css` 中的色板与字号阶梯。任意两页并排必须像同一家机构出品。
2. **信息的形状决定版式**：先判定本页是「非对称洞察」「因果机制」「2×2 象限」「多维矩阵表格」「话题屋架构」还是「社媒实证拆解」，直接选用 `layout_taxonomy.md` 对应的坐标网格与 `primitives/*.svg` 骨架，禁止把任何内容都塞进均分三栏方框。
3. **尺度对比拉开层级**：大数指标（`52–72px`）、水印编号（`120–140px`）、主标题（`40–46px`）、模块小标题（`24–28px`）、正文（`18–20px`）、辅助图注（`13–15px`）档位清晰，相邻层级差距一眼可辨。
4. **整套节奏起伏**：多数页面采用「75% 浅色底 + 底部深色定海神针」；在章节转折、核心大数看板或关键战略卡位页，可偶发穿插「深空黑/蓝黑满版底（Dark Mode Spotlight）」形成呼吸感，避免连续 3 页使用完全相同的三栏骨架。

## 三、完成前自检（对照 `check` 测量与 PNG 大图）

`check` 会自动运行 `validate_svg_layout.py`（拦截横线切字、Emoji、胶囊溢出、文字重叠、越界与未定义 CSS 变量）并给出 `design_observations` 测量。逐页查看 **PNG 渲染大图**，回答以下五问并写入 `inspect --first-glance` 与 `--design-check`：

1. **75:20:5 与去框化**：页面是否守住了唯一品牌强调色？有没有偷画彩虹色或超过 2 层的框套框？
2. **天际线与饱和度**：Action Title 是否直给观点？竖卡下半截有没有超过 25% 的空洞留白？底部 `y=918` 定海神针是否稳稳托底？
3. **三道防线零死角**：分割线有没有切到多行 `<tspan>` 的下沿？胶囊文字有没有贴边或溢出？有没有混入任何系统 Emoji？
4. **证据与图文咬合**：真实截图/产品图是否获得了足够面积？图片底层占位文字是否已清理干净？
5. **跨页节奏**：与前后页放进联系表同看，骨架是否有主次起伏？
