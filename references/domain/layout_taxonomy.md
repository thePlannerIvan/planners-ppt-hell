# 信息关系与版式选择

先问本页要证明什么，以及信息是什么关系，再选所用模板 primitives。具体坐标和颜色以所选包 SPEC.md 为准。

| 信息关系 | 可选组织 |
|---|---|
| 主张与证据 | 一个焦点与明确证据区，留足图表/截图阅读面积 |
| 比较 | 对齐比较维度、口径与单位，显式标出差异 |
| 因果或流程 | 按推导/时序排列，连接方向可辨 |
| 层级或架构 | 用层级和归属关系组织，不伪造因果箭头 |
| 多维数据 | 表格、象限或矩阵，清楚标轴与定义 |
| 转折、开场或收束 | 聚焦一个判断，密度与任务匹配 |

过载时先拆解或提炼内容，不靠无止境缩字解决。留白有助阅读，不为填满容器追加无关信息。连续页面可共享结构；只有内容关系变化时才需要换布局。
选 agency-social-proposal 或 consulting-product-strategy 并需要历史坐标示例时，读 flagship_layout_examples.md。示例属于两套主题，不能覆盖其他品牌或视频规则。
