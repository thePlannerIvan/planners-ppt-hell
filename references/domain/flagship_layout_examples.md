# 内置旗舰布局历史示例

仅供两个内置旗舰主题参考；坐标、色盘、比例是示例，不是通用规则。当前包 SPEC.md 与原语优先。

# 信息组织、1920×1080 坐标网格与版式原语指路（Layout Taxonomy）

制作每页前先做信息判断：本页证明什么结论？信息关系是**非对称洞察、因果传导、2×2 象限、主次对比、战略架构屋、高密度作战表，还是社媒/产品实证**？

为了杜绝模型面对 1920×1080 空白画布盲算坐标或把一切内容都塞进均分三栏方框，本文件为 **L01–L15 每个版式家族提供推荐的 1920×1080 像素坐标网格**，并直接指路到内置双旗舰模板包（`agency-social-proposal` 与 `consulting-product-strategy`）下的 **`primitives/*.svg` 原语骨架文件**。画页时优先复制对应原语骨架改写，或按下列坐标网格排布。

---

## 1. 页面模式（`rational` vs `emotional`）

### `rational`（理性论证页，占整套方案 80%–85%）
- 用于：市场诊断、数据洞察、策略屋、机制推导、竞品对比、内容矩阵、战役排期、ROI 测算。
- 硬标尺：严格执行 `style_system.md` 的 **1920×1080 天际线契约**（顶部 Action Title + 正文安全区 `x=80..1840, y=196..896` + 底部 `y=918, h=76` 定海神针结论横幅），保留完整数据口径、分母、时间范围与来源。

### `emotional`（情绪/停顿页，占整套方案 15%–20%）
- 用于：封面（L01）、篇章转场（L02）、核心战略追问（L07）、金句宣言（L08）、收束页（L15）。
- 硬标尺：字数精炼、强明暗或尺度对比（如左黑右灰黄金分割、深空黑满版聚光灯），单一记忆点，不堆砌密集论证。

---

## 2. 六大反偷懒铁律（Anti-Laziness Gate）

1. **严禁万物皆三栏均分方卡**：除非确实是三个等权支柱（且下半截必须内嵌实证盒撑满），否则优先选用非对称 1:2、瑞士无框水印网格、战略屋或斑马纹大表。
2. **严禁无比较维度的假双栏**：左右对比必须有显式对比维度或「左窄暗灰旧范式 vs 右宽亮色新主张」的视觉倾向。
3. **严禁证据缩成邮票**：有小红书爆文截图、产品实拍或核心图表时，证据区面积必须占正文区 **35%–55%**。
4. **严禁竖卡下半截留白 > 25%**：卡片高度超过 `450px` 时，底部必须内嵌案例/话题/数据验证子盒。
5. **严禁连续 3 页同构**：相邻页面必须在「上下结构 ↔ 左右非对称 ↔ 矩阵网格 ↔ 象限/表格」之间交替。
6. **严禁靠缩字硬塞超载文案**：文字超载时拆页或提炼为无竖线斑马纹表格，不准把正文字号缩到 `< 14px`。
