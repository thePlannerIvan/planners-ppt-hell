# `dark-titanium-cockpit` — 瑞士先锋排印与战略驾驶舱模板包（SPEC）

> **设计哲学**：源自瑞士国际主义平面排版（Swiss International Typographic Style）与前卫新野兽派（Neo-Brutalist Typographic Cockpit）。彻底摒弃泛滥而碎裂的 SaaS 灰色 Bento 胶囊框堆砌，回归**极端字阶对比（145px vs 18px）**、**50%–70% 负空间呼吸感**、**细发丝线网格（1.5px Razor Hairline）**与**单点高伏特破局色**。

## 二、 1920×1080 空间网格与排印阶梯（见 `skyline_shell.svg`）

- **安全边界（Safe Margins）**：左右统一留白 100px（有效内容区 `x = 100 .. 1820`，宽 1720px）。
- **天际线母版（Skyline Header）**：统一位于 `y = 80 .. 105`，包含 `XX / 33 · SECTION TAXONOMY` 与右侧胶囊 `[ INDEX ]`。
- **四角十字准星（Cross Markers）**：四角关键网格交界处保留 `+` 细线坐标（如 `(100, 100)`, `(1820, 100)`），标定仪器感。
- **排印字阶（Scale Ladder）**：
  - **巨幅陈述**：`145px`（Cover）、`140px`（Broken Syllable）、`110px`（Poster）
  - **纤细背景大数**：`280px - 320px`（16:9 / Ghost Slender Numbers，浅灰发丝）
  - **数据巨数**：`110px - 130px`（如 85.6M Hero KPI, +82% Multiple）
  - **大栏目/议程标**：`72px – 76px`（Scope of Work / Agenda / Playlist）
  - **主张断言/大字行**：`44px – 52px`
  - **正文大字/二级标题**：`26px – 32px`
  - **说明与事实段落**：`20px – 24px`
  - **法定易读底线**：**全页任何标注、标签、来源严禁低于 18px**。

## 四、 防翻车开发红线

1. **绝对禁止 `rotate(...)` 变换**：PPTX 转换器对 SVG 的 `transform="rotate(...)"` 支持存在投影与形变缺陷，纵向文本必须采用字符纵向堆叠（Stacking），几何旋转必须使用预计算坐标。
2. **严禁 Bento 灰框嵌套**：内容组织依靠发丝线、尺度悬殊的字阶与纯色块引导，不要在每一个段落外面套灰色圆角矩形。
3. **字号红线**：严格执行全页无 `<18px` 文字。
4. **分割线禁切文字（`LINE_CROSSES_TEXT`）**：所有细分割线严禁穿透文字元素的坐标包围盒，遇到文字必须断开或置于外部。
5. **负空间底线**：每一页必须保持至少 50% 的留白率，克制即权威。
