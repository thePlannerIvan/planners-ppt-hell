# `agency-social-proposal` — 整合营销与社媒种草提案旗舰模板包（SPEC）

> **审美基因**：源自美津浓小红书种草全案与官号提案的人工精修定稿（75 分 → 90 分去框化升级版）。结合**高对比杂志编辑感（Swiss Editorial Grid）**与**实战种草颗粒度（XHS Mockup + 话题屋 + 斑马纹作战表）**。
